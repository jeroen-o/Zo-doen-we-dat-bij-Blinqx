# Blinqx – cultuur, kaartjes & tegeltjes

Zet deze map in de root van je GitHub-repo en zet GitHub Pages aan (Settings → Pages → branch `main`, folder `/`).

- `index.html` — Onze cultuur (met tabblad naar Kaartjes & Tegeltjes)
- `kaartjes.html` — Kaartjes & Tegeltjes tool
- `teksten.js`, `assets/` — tekstbibliotheek en foto's die de tool laadt (laat de mappenstructuur intact)

Opmerking: openen via `file://` werkt niet volledig (de browser blokkeert dan het laden van `teksten.js`); via GitHub Pages of een andere webserver wel.
